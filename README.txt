AI Trading Analyst V1
نسخة أولية محلية مبنية من مشروع Syria Auto Store V1.
المزايا: لوحة تحليل، شارت تجريبي، RSI/MACD/حجم، دعم ومقاومة، سيناريوهات، إدارة مخاطر، مستويات تعليمية، وسجل محلي.
ملاحظة: البيانات تجريبية وليست أسعار سوق حقيقية. لا توجد ضمانات للربح.
للاستخدام الإنتاجي: ربط مزود بيانات سوق، API للذكاء الاصطناعي، مصادقة وقاعدة بيانات وتنبيهات حقيقية.
