سوريا أونلاين — V23 GLOBAL MARKETPLACE

هذه النسخة مبنية كمتجر Marketplace عربي/إنجليزي/تركي، مستوحى من أنماط المتاجر العالمية (اكتشاف المنتجات، البحث، الأقسام، السلة، الحساب، الطلبات ولوحة الإدارة) بدون نسخ هوية أو محتوى مملوك لموقع بعينه.

الموجود:
- الصفحة الرئيسية + عروض + الأكثر مبيعاً + المنتجات الحديثة + المنتجات المشاهدة مؤخراً.
- بحث واقتراحات + تصفية + ترتيب + أقسام وفئات فرعية.
- صفحة تفاصيل المنتج + خيارات + مواصفات + منتجات مشابهة + مفضلة + مقارنة.
- سلة + كوبون + شحن + إتمام طلب.
- تسجيل دخول/إنشاء حساب عبر Supabase.
- الملف الشخصي + العناوين + طرق الدفع + الطلبات + الإرجاع + خدمة العملاء.
- لغات عربية/English/Türkçe.
- لوحة تحكم محمية: المنتجات، الأقسام، الاستيراد CSV، الطلبات، الربط.
- نقطة API جاهزة لربط Trendyol عند وضع بيانات Seller كمتغيرات بيئة على الاستضافة.

قبل الإطلاق التجاري:
1) تأكد من بيانات Supabase وسياسات RLS والصلاحيات.
2) أضف مفاتيح Trendyol الحقيقية على الخادم فقط إذا كان حسابك مخولاً للـAPI.
3) اربط بوابة دفع حقيقية مرخصة بدل نموذج الدفع التجريبي.
4) راجع الشحن والمرتجعات والضرائب وسياسات الخصوصية حسب نشاطك ومكان البيع.
5) استبدل بيانات المنتجات التجريبية بمنتجاتك/مورديك الفعليين.
